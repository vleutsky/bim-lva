Как загрузить плагин

Для запуска .dll в AutoCAD / Civil 3D выполните 4 шага:

  1. Скачайте архив с Яндекс.Диска и распакуйте его.
  2. Обязательно: ПКМ по .dll → Свойства → галочка «Разблокировать» → Применить.
  3. В Civil 3D введите NETLOAD.
  4. Выберите файл, затем введите команду плагина.

Совет: для автозагрузки используйте APPLOAD → «Содержимое» и добавьте файл в список.
