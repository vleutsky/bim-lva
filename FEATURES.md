## Заметки

- Канонический стабильный файл: `bim-lva-composer-ifc.html` (без ИИ)
- Версия с ИИ: `bim-lva-composer-ai.html` (+ `ai-bridge/`, `ai-client.js`, `AI-LOCAL.md`)
- Ветка: `cursor/ifc-bulk-edit-37f9` → периодически merge в `main`
- Браузер-only: без серверного Revit/Tekla SDK
- **RVT не открыть в принципе**: геометрия Revit в закрытом формате, открытых
  реализаций не существует. Файл распознаётся, но вместо загрузки показывается
  объяснение с указанием экспортировать в IFC. Библиотеки вроде `@phi-ag/rvt`
  достают только версию Revit и картинку предпросмотра — геометрии там нет.
- ИИ только через localhost bridge; Pages — для стабильного Composer

## Вендоры и проверки

- Зависимости лежат локально в `assets/vendor/` — three, three-mesh-bvh,
  web-ifc (+ wasm), geotiff, jszip, qrcode, dwgdxf (+ wasm), supabase, шрифты. Сайт остаётся
  статикой: `assets/vendor/` коммитится, шага сборки при деплое нет.
- Пересобрать после смены версии в `package.json`: `npm ci && npm run vendor`.
  Версии видны в `assets/vendor/VERSIONS.json`.
- На CDN осознанно оставлены pyodide (DXF через ezdxf) и gdal3.js (ECW) —
  десятки мегабайт ради редкой операции.
- `npm run serve` — локальный просмотр на http://127.0.0.1:8080. Двойным щелчком
  по файлу вьювер не открыть: ES-модули, importmap и wasm требуют HTTP.
- `npm run portfolio` — пересобрать `portfolio.html` из `index.html`. Это версия
  сайта для отклика на вакансии: без блока «Разработка под заказ», без кнопки
  доната, раздел услуг переписан в «Навыки». Ссылку в hh давать на неё, без
  якоря: `https://vleutsky.github.io/bim-lva/portfolio.html`
- `npm run test-license` — проверка формата лицензии на совместимость с
  `LicenseGate` из репозитория LvaBim: каноническая строка, формат дат .NET
  (семь знаков дробной части — иначе подпись не сойдётся после разбора JSON),
  RSA-SHA256/PKCS#1, подделки, просрочка, привязка к машине.
- `npm run edge-bundle` — пересобрать `bundled.ts` для развёртывания функции
  через дашборд без CLI. Правки вносить в исходники, не в сборку.
- Лицензии: инструкция по развёртыванию и проверка ключа в плагине (C#) —
  `supabase/functions/license-issue/README.md`. Ключи выпускает только сервер;
  на статическом сайте защищённого места нет и быть не может.
- `npm run check-site` — проверка страниц: заглушки вроде `YOUR_LINK_HERE`,
  битые внутренние ссылки, пустые якоря, локальные 404. Гонять перед рассылкой
  резюме.
- `npm run smoke` — дымовой тест в Chromium: страница, загрузка IFC, пикинг,
  уведомления, прогон коллизий. Гоняйте перед merge в `main`.
- Pages отдаёт `main`; preview-URL для веток у Pages нет. Правки вьювера сначала
  живут в `bim-lva-composer-ifc-preview.html` (`npm run preview`), и только
  после проверки — в рабочем файле.
- `node tools/bench-pick.mjs [N]` — замер отклика на клик.
- `bim-lva-composer-ai.html` пока остался на CDN: вендоры и BVH в него не
  переносились.
