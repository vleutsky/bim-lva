# Дорожная карта: Composer рядом с InfraWorks

Рабочий документ, не маркетинговый. Состав продуктов — из кода Composer и ленты
Civil в `LvaBim`, не из памяти. Сравнение с InfraWorks 2025/2026 по публичному
описанию Autodesk (Model Builder, component roads, drainage, bridges, traffic,
IMX → Civil 3D).

InfraWorks — **концепт инфраструктуры в контексте местности**. Мы уже идём по
этой тропе: площадка с карты подписана «как в InfraWorks», ось + план/профиль/
поперечник + откосы до рельефа — это их «нарисовал дорогу на земле». Цель карты
не скопировать IW целиком, а закрыть тот кусок, ради которого генпланист
открывает IW **перед** Civil: площадка, ось, поперечник, объёмы, картинка
заказчику, выдача в Civil.

Плагин Civil 3D (88 команд: генплан, НВК, BIM/IFC, BIM Bridge, электрика,
сети связи) — **производство в чертеже**, не конкурент IW. Его дорожка
отдельная (лицензии, бесплатные команды). С IW сравниваем Composer.

---

## Позиция

| | InfraWorks | BIM.LVA Composer | Плагин Civil |
|---|---|---|---|
| Где | Десктоп, подписка Autodesk | Браузер, файлы не уезжают | Civil 3D 2022–2026 |
| Роль | Концепт в контексте | Концепт + сводка BIM | Рабочий чертёж |
| Сильная сторона | Стили дорог, пересечения, мосты, водосборы, трафик, IMX | IFC/DWG/LandXML в одной сцене, координация, русская выдача DXF | Трубы, генплан, мост в Civil |
| Слабая | Тяжёлый, лицензия, IFC-сводка не его работа | Нет стилей IW, нет IMX, DEM с карты грубый | Не концепт на глобусе |

Composer **уже сильнее IW** как сводка моделей (IFC, коллизии, BCF, Pset).
IW **сильнее** как конструктор дороги на местности. Дорожная карта добивает
второй столбец ровно настолько, чтобы IW на стадии «площадка + трасса» стало
не обязательно открывать.

На сайте (`composer.html`) по-прежнему верно: это не расчётный комплекс.
Гидравлику, виражи по AASHTO, параметрические мосты и симуляцию трафика
**не берём** — часть этого уже живёт в плагине Civil (НВК, BIM Bridge).

## Матрица: что есть / дыра / не берём

Легенда: **есть** — в Composer сейчас · **дыра** — имеет смысл закрывать ·
**нет** — сознательно не копируем IW.

### Контекст местности (Model Builder)

| Возможность IW | Composer сейчас | Решение |
|---|---|---|
| Глобус, рамка/контур, снимок + рельеф | Есть (ESRI/OSM, Terrarium, 200 га, СПб по умолчанию) | Держать, не раздувать |
| Дороги и здания OSM как объекты модели | Нет: только картинка + DEM | **Дыра №1** — контекст «как живой город» |
| ArcGIS / свои слои GIS | Нет | Позже, если будет заказ |
| Облако точек → рельеф и фичи | Нет | Не в браузере пакетом IW; свой LandXML/GeoTIFF уже открывается |
| Погода, storyboard, AR | Нет | **Не берём** |

Глобальный DEM ~10–30 м: для «ось на карте → откосы» годится, для объёмов и
посадки здания — нет. Это уже зафиксировано в `FEATURES.md` п. 33. Свой
LandXML / IFC / GeoTIFF поверх карты — рабочий рельеф.

### Дорога

| Возможность IW | Composer сейчас | Решение |
|---|---|---|
| Planning / component road на местности | Ось + кромки + шаблон (точки, связи, формы) + коридор | Есть каркас |
| Сборка: полоса, бордюр, обочина, кювет | Фигуры на поперечнике, пресеты (покрытие / бордюр / обочина / кювет / городская) | Есть; не хватает **библиотеки стилей**, не одноразовых кнопок |
| План + профиль + сечение | Одно окно, правка Z на вершине, шаг сечений прямой/кривая | Есть |
| Откосы к рельефу 1:m | Есть (лучи + TIN, как у площадки) | Есть |
| Земля на сечении до края / откоса | Есть | Есть |
| Пересечения, кольца, примыкания | Нет | **Дыра №2** — сначала простое примыкание, не кольцо IW |
| Вираж, разгонные, разметка | Нет | Вираж — после вертикальных кривых; разметку не обещать |
| Вертикальные кривые профиля | Ломаная по вершинам | **Дыра №3** |
| Объём коридора (насыпь/выемка вдоль оси) | Объёмы есть у площадки и у откосов кромок; коридор — геометрия, не ведомость | **Дыра №4** |
| Оптимизация плана/профиля «сам подберёт» | Нет | **Не берём** (чёрный ящик IW) |

### Сооружения и сети

| Возможность IW | Composer / плагин | Решение |
|---|---|---|
| Параметрический мост и тоннель | В Composer нет; в Civil — вкладка «LVA · BIM Bridge» (5 команд) | Мост — в плагине, не клонировать IW |
| Водосбор, culvert, сеть водоотвода, HGL/EGL | В Composer нет; в Civil — «LVA · НВК» (40 команд) | Сети — в плагине |
| Железная дорога как стиль IW | Проезд локомотивом по оси есть; проектирования пути нет | **Не берём** как IW-модуль |
| Трафик, дальность видимости | Нет | **Не берём** |

### Выдача в Civil 3D

| Возможность IW | Composer сейчас | Решение |
|---|---|---|
| IMX → трасса, профиль, коридор в Civil | Нет | **Дыра №5** — не IMX, а LandXML Alignment + Profile + Surface, который Civil уже открывает (чтение LandXML у нас есть, запись оси/профиля — нет) |
| DXF поперечников и кромок | Есть (R12, мировые координаты) | Держать |
| TIN площадки / откосов в Civil | LandXML площадки пишется | Дописать TIN коридора |

### Сводка и координация (здесь IW слабее)

Есть и **не отдаём**: IFC/DWG/DXF/LandXML в одной сцене, абсолютные координаты,
коллизии, BCF, сравнение версий, ведомость, правка Pset, пакет экспертизы в
ссылке. Это наше отличие, не паритет с IW.

## Очередь (только то, что двигает паритет с IW)

Порядок — по тому, что генпланист замечает в первые полчаса. Не по «красоте
как в ролике Autodesk».

### 1. Контекст: дороги OSM на площадке

После «Загрузить» с глобуса в сцене — не только снимок и DEM, а **линии дорог**
(и по желанию контуры зданий выдавливанием) из того же охвата. Тогда ось
сажается вдоль существующей улицы, а не на пустую отмывку.

Не тащить весь OSM мира: только контур площадки, как сейчас 200 га.
Лицензия тайлов не трогает вектор OSM (иные условия, чем Яндекс/Google).

Без этого IW выигрывает с первого кадра, какой бы поперечник ни был.

### 2. Вертикаль профиля как трасса, не ломаная

Вершины профиля уже правятся по Z. Не хватает **вертикальных кривых** (ВК)
между переломами — иначе картинка «как в IW/Civil» разъезжается с выдачей.
Пикетаж и таблица остаются по вершинам оси; земля на профиле по-прежнему
густая.

### 3. Объём коридора

Считать насыпь/выемку по поперечникам: шаблон vs земля, с откосами.
Цифра на палитре и в CSV. Без этого IW «Calculate Earthwork» остаётся
причиной открыть его «на пять минут». Площадки и откосы кромок уже считают
объём — тот же принцип, другая интеграция.

### 4. Выдача в Civil без картинки

Запись LandXML: Alignment (план с радиусами), Profile (отметки / ВК),
Surface (TIN коридора или откосов). Civil это читает штатно. IMX не
изобретать — формат закрытый.

DXF поперечников оставить как черновик для нанокада и старых шаблонов.

### 5. Примыкание, не кольцо

Две оси, одна вливается в другую: секущая, шаблон на ответвлении, бровка
не лезет в основную проезжую. Кольцо и «standard intersection» IW — после
того, как примыкание перестанут обходить вручную.

### 6. Библиотека стилей поперечника

Пресеты уже есть карточками. Нужно **сохранить свой шаблон** (бордюр + кювет
+ слои одежды + откосы) и выбрать его на следующей оси. Это их Component
Road assembly без каталога AASHTO.

## Что не ставим в очередь «как IW»

- Симуляция трафика и дальность видимости.
- Параметрические мосты/тоннели в браузере (есть BIM Bridge в Civil).
- Водоотвод и гидравлика (есть НВК в Civil).
- Оптимизатор плана «сам найдёт дешёвую ось».
- Погода, сюжет, AR.
- Яндекс/Google/2ГИС подложкой (лицензия, не техника).
- RVT напрямую.

Если заказчик просит мост или ливнёвку на концепте — это сценарий плагина
Civil или IFC с мостом в сводку, не новый движок в Composer.

---

## Плагин Civil — рядом, не внутри сравнения

Отдельный хвост, на IW не завязан:

- разметить 86 команд на платные/бесплатные (`RequiresLicense`);
- добить выпуск `license.lic` с веба (секрет RSA, функция `license-issue`);
- не выдумывать продукты: лента как в исходниках, витрина 03…09.

Связка с этой картой одна: **Composer отдаёт LandXML/DXF → Civil подхватывает
плагином**. Пока выдачи оси/профиля нет, связка — ручная.

## Как пользоваться этим файлом

- Спорим о приоритете — правим очередь здесь, не плодим второй список.
- Берём пункт в работу — карточка в `FEATURES.md` с номером и критерием
  проверки (`npm run smoke` / отдельный тест).
- На сайт (`composer.html`) краткую таблицу «рядом с InfraWorks» — только
  после явного «публикуй»: это уже претензия на рынок, не рабочая память.
